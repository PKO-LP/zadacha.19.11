# Сценарии ручных проверок (v1.0)

**Проект:** MyПицца — учёт заказов пиццерии.
**Дата проверки:** 19.11.2026. **Среда:** Windows, Python 3.14 + Tkinter.
**Проверяющие:** Ананьев Александр, Ларионов Дмитрий (12ТЭС-26).

| № | Сценарий и действия | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| TC-1 | Выбрать «Пепперони», «Средняя 30 см», кол-во `2`, нажать «Добавить заказ» | Заказ №1 добавлен в таблицу, сумма `1430 ₽`, статус «Готовится» | Заказ №1 появился в таблице с суммой `1430 ₽` и статусом «Готовится» | Пройдено |
| TC-2 | Оставить количество пустым и нажать «Добавить заказ» | Предупреждение «Укажите количество пицц», запись не создана | Показано окно предупреждения, список не изменился | Пройдено |
| TC-3 | Ввести количество `0` или `abc` и нажать «Добавить заказ» | Предупреждение об ошибке ввода, запись не создана | Показано окно предупреждения, запись отклонена | Пройдено |
| TC-4 | Кликнуть по заказу №1, изменить кол-во на `3`, нажать «Сохранить изменения» | Данные в таблице обновились, сумма пересчитана на `2145 ₽` | Заказ №1 обновлён, новая сумма `2145 ₽` | Пройдено |
| TC-5 | Выбрать заказ №1 и дважды нажать «Следующий статус» | Статус меняется: «Готовится» → «Готов» → «Выдан» | Статус последовательно сменился на «Готов», затем на «Выдан» | Пройдено |
| TC-6 | Нажать «Следующий статус» для заказа со статусом «Выдан» | Информационное сообщение, что заказ уже выдан | Показано окно «Заказ №1 уже выдан» | Пройдено |
| TC-7 | Ввести в поиск «Пепперони» и выбрать фильтр «Выдан» | В таблице показаны только выданные заказы с «Пепперони» | Таблица отфильтрована корректно, кнопка сброса возвращает все записи | Пройдено |
| TC-8 | Выбрать заказ, нажать «Удалить заказ» → «Нет», затем повторить → «Да» | При «Нет» заказ остаётся; при «Да» удаляется из списка | Подтверждение работает корректно, после «Да» строка удалена | Пройдено |
